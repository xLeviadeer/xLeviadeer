### [MCLCE Texture Converter](https://github.com/xLeviadeer/MCLCE-Texture-Converter?tab=readme-ov-file)
The MCLCE Texture Converter is a texture conversion tool to convert texture packs from Minecraft Java or Minecraft Bedrock to Minecraft LCE.

I created the MCLCE Texture Converter to address the lack of tools for converting texture packs from other versions of Minecraft to Minecraft Legacy Console Editions. It is designed as an all-encompassing texture conversion solution, with an emphasis on extensibility and reuse. The converter can be used independently by other developers and called from programming languages other than the language in which it was developed.

#### About the MCLCE Texture Converter
- converts almost all game textures
- handles numerous permutations including but not limited to: different input and output versions, different texture sizes, different input and output game editions, and different generation directives.
- able to be called via the command line
- user friendly interface

#### Key Work
- wrote code to handle numerous different circumstances at once 
- wrote extension [documentation](https://github.com/xLeviadeer/MCLCE-Texture-Converter/blob/main/Adding%20CustomProcesses.md) with examples and explanations
- created and iterated on a user interface
